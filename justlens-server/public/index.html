Kelola Data Master via Excel (.xlsx)

Ekspor data master ke Excel, atau impor file Excel dengan format kolom baku (Otomatis Insert jika baru & Update jika kode/ID sudah ada).

1. Master Barang (In-House & Outsource)

Format Kolom: Kode_Barcode, Nama_Barang, Kategori, Harga_Modal, Harga_Jual, Stok_Awal, Satuan

2. Data Supplier Bahan Baku

Format Kolom: ID_Supplier, Nama_Supplier, No_Telepon, Alamat

3. Pricelist & Vendor Outsource

Workbook 2 Sheet: Vendor_Outsource (Biaya Modal/m²) & Finishing_Options (Harga Finishing)

4. Cetak Label Barcode ke Word (.docx)

Menghasilkan berkas Microsoft Word (.docx) berisi grid label stiker barcode produk, nama barang, dan harga jual yang rapi.
